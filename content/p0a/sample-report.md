## Whose date is this, and how was it calculated?

The sample uses **1 January 2000**, not a real customer's birthday. We chose it because anyone can check it. The Smithsonian's *Living Maya Time* gives the full Maya date for that day as 12.19.6.15.2, 11 Ik' 10 K'ank'in. [1]

Our calculation runs as follows. The Julian Day Number of 1 January 2000 is 2,451,545. Subtracting the GMT correlation constant 584,283 leaves 1,867,262 days. Number = ((1,867,262 + 3) mod 13) + 1 = **11**. Day sign index = (1,867,262 + 19) mod 20 = **1**, which is Ik'. [2] Every paid report uses the same method, labelled *gmt584283-proleptic-gregorian-v1*. The name "Spectral" for the number 11 comes from the modern Dreamspell system, and the report says so on its number page.
